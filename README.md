# Prodigy Generative AI - Task 03

## Text Generation Using Markov Chains

This project demonstrates text generation using a Markov Chain model built with Python.

### Technologies Used
- Python
- Google Colab
- Random Module
- Regular Expressions

### Implementation
- Created a custom text dataset.
- Built a Markov Chain using consecutive words.
- Generated new text based on previous words.
- Tested text generation with different starting words.

### Output
The model generates text using learned word transitions from the custom text dataset.

### Platform
Google Colab
